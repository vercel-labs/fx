# Security policy

Report security vulnerabilities in fx and libfx through the [contact page](https://fx.sh/contact). Don't report them in a public issue, pull request, or discussion.

Include what someone needs to reproduce the problem: the affected version (`fx --version`, or the libfx package version), the steps, and the impact you observed. Leave secrets and personal data out of the report.

When you can, confirm the problem on the latest release first. fx checks for updates in the background, and `fx upgrade` installs the latest release right away.
